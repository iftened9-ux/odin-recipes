# Odin Recipes

A simple recipe website built as part of [The Odin Project](https://www.theodinproject.com/) Foundations course. This project focuses on practicing semantic HTML structure and basic CSS styling.

## About

Odin Recipes is a small multi-page website that showcases a collection of recipes. Each recipe has its own dedicated page with a photo, ingredient list, and step-by-step instructions.

## Features

- Home page listing all available recipes with images
- Individual recipe pages with ingredients and preparation steps
- Simple, clean navigation between pages

## Built With

- HTML5
- CSS3

## What I Practiced

- Semantic HTML structure
- Linking multiple pages together
- Working with images and lists
- Basic responsive styling
